# 录入工作流（零命令行）

> 给使用者的唯一操作手册。一切在网页内完成，最后双击「同步并打包.bat」。
> 旧版纸面条目已归档到 `_archive/mirage-v1/`（来源署名与说明都在，随时可翻）。

## 四步走

### ① 新建条目

道具 Tab → 「＋ 新增道具」：

| 字段 | 填法 |
| --- | --- |
| id | `mirage-t-类型-点位`，如 `mirage-t-smoke-window`（小写英文+连字符） |
| 标题 / 一句话怎么扔 | 中文，一句话要能单独看懂（如「贴白车油桶角直接投，火烧超市窗口架点」） |
| 起点 / 目标 | 用报点图里的中文名（如 白车、B 二楼、连接口），会联动钻取 |
| 键位 · 移动 · 投掷 | 左/右/双键 · 原地/W/Shift/Shift+W/跑 · 直投/跳投/蹲跳投 → 自动拼成投法徽章 |
| 阶段 | 该道具主要用在哪个阶段（决定列表分组） |
| 标签 / 报点关联 | 报点关联填报点图里的地名（逗号分隔），钻取和搜索靠它 |

保存后状态为「待验证」。

### ② 补齐三张图

详情页翻图面板：每个槽位点「上传/替换」选图即可——
- 自动压缩（宽 ≤1920、单图 ≤1MB），不用提前处理；**GIF 动图原样保留**（不压缩不缩放，动画完整），建议 ≤5MB；
- 未关联项目文件夹时暂存浏览器（角标「未同步」），关联后自动写盘；
- 需要补充落点视角等，用「扩展槽」：上传后自动成组，可随时删除。

三张图建议：**站位**（含地标）→ **瞄点**（准星清晰）→ **落点&效果**（烟成/火铺/闪爆）。

### ③ 游戏内稳定复现 → 标记已实测

真的在游戏里复现过、确认点位没问题时，点详情页状态徽章（两段确认）→ 变绿，
自动记下当天日期。没把握就先留着橙色，别急着标。

### ④ 同步打包

顶栏出现「● 有未同步修改」时，双击项目根目录的 **同步并打包.bat** ——
它会把网页里的修改固化到项目数据，并刷新 dist 里给朋友的 zip。
做完这一步，一切落盘，网页关掉也不丢。

## 批量通道（两条，并存）

- **自助通道 = 分拣台（推荐）**：道具 Tab →「📥 分拣台」。把素材截图按「子文件夹=地图中文名」
  放进项目根目录的「文件夹批量录入」，打开分拣台：素材池点图 → 点坑放下（也支持拖文件/点坑上传），
  一行一条道具填代号/标题/起点/目标/投法，「全部导入」一键入库——已实测的勾着，
  导入即绿；没把握的去掉勾，导入为待验证。素材全部用完的子文件夹自动移进「已录入/」。
  分拣台列补充（R3-L12/L13/L14）：**标题自动取站位图文件名**（如「警家单向烟.png」→ 标题「警家单向烟」，可改）；
  **文件名里带关键词还会自动抓字段**——类型（烟/闪/火/雷）、投掷（跳投/蹲跳投/直投/平投/轻抛）、
  移动（跑投/走一步/W一步/W跳投/Shift+W/蹲投）、键位（左键/右键/双键），词写成即可，导入前可改；
  **已实测默认不勾**（实测过才勾，或表头 ▾ 一键全勾）；**标签**列逗号分隔选填；
  **落点📍**列点开小地图点击即可调精确落点（不调停在报点中心）——都不填也正常录入。
- **agent 通道**：把整理好的文件夹 + 一句话需求发给开发会话（ZCode），由工具脚本清单驱动入库
  （历史用法见「素材导入」台账记录）。适合一次几十张、需要裁剪拼图分析的场景。

两条通道最终都走同一套覆盖层与写盘管线，导完双击「同步并打包.bat」固化。
