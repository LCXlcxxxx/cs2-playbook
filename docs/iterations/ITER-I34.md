## 根因速览（已核实）

- smoke-12 三方数据：盘上 .md（14:46）＝side CT / difficulty 2 / title 警家补A2楼烟；
  data.js（12:49 构建）＝side T / difficulty 3 / title 警家补A2**烟**（更老）；
  浏览器暂存＝用户更晚的编辑（title 警家补A二楼烟）。三个值互相打架，表单显示哪个取决于暂存对账状态。
- ef-save 基线已是 diskEntries（页面加载时的盘值快照，I19）——但**页面开着期间**盘被继续写（分拣台导入、
  开发会话 build），diskEntries 就旧了；表单初值更是一直取合并显示值。
- 修法：编辑器**打开时**（已关联且非新增）直接读 `data/entries/<id>.md` 现解析为表单初值与保存基线；
  读失败/未关联 → 回落现状（合并值），行为不变。
