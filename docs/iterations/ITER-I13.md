# 迭代 I13 开发包 — 编辑器选报点（地图弹窗）+ 移动枚举扩「W 一步」+ Esc 返回

> 用法：在项目根目录 `D:\AI agent\ZCode data\CS2` 打开新的 ZCode 会话，把下面代码块整段粘贴执行。
> 背景：用户录 Mirage 火时三个痛点——起点/目标/报点关联要手打（应从战术板地图选）、
> 目标其实常有多个报点（现在塞逗号串导致钻取匹配失效）、移动枚举缺「W 一步跳投」。
> AGENTS.md §3.1 已改：move 枚举加 walk-step（W 一步）；target 支持行内数组多选。

## 粘贴提示词

```text
按 AGENTS.md 规范执行查看器迭代（迭代 I13）。涉及 assets/js/app.js、tools/pb.py、style.css。
动手前先 grep 核实：targetIs（单值比较）、M 投法徽章表、编辑器 move 下拉选项、
pb.py 里 move 枚举校验表（grep "shift-w"）与 target 的解析/写回路径。

一、数据层：target 支持多选（向后兼容）
1. 解析与写回双向兼容：target 为标量 → 视作单元素；条目保存时若是多值 → 写行内数组
   （target: [二箱, 电梯位]），单值仍写标量。dumpEntryMd 与 pb.py 解析器保持严格互逆。
2. app.js targetIs：e.target 为数组时 any-match，标量行为不变。
3. 徽章与钻取联动：详情页「起点 → 目标」多目标用「 / 」连接；起点/目标模式钻取对数组
   逐值匹配（originIs 逻辑不动）。
4. 兼容迁移：编辑器打开旧条目若 target 含逗号串（如「二箱，电梯位」），按逗号拆成多值
   预填到选择器；保存后即落成数组。
5. lint：target 每个值若不在该图报点表 → WARN（不阻塞）；不改动 spots 的既有校验。

二、编辑器：起点/目标/报点关联 地图选点器
1. 起点 = 单个 chip 显示当前值（× 可清除），点 chip 或「在地图上选」打开选点弹窗
   （默认落在「起点（单选）」模式）。**不做长下拉**——全图报点名太多，列表里难找，
   选起点本质是空间操作：在地图上点自己站的位置。保留「手动输入…」小链接兜底
   （罕见非报点名）。
2. 目标 = 多选；报点关联 = 多选。表单里显示为 chips（点 chip 的 × 移除）；
   每个 chips 区右侧「在地图上选」按钮 → 弹出小地图选点弹窗：
   - 弹窗复用雷达图 + 报点标签（样式同编辑器地图），顶部三个模式页签：
     「起点（单选）」「目标（多选）」「关联（多选）」，进入时定位到发起字段对应模式；
   - 弹窗顶部一个搜索框：输入关键字实时过滤报点标签（如输入「窗」只剩
     窗户/超市窗口），报点名太多时靠它找；
   - 点报点标签即选中/取消：起点模式点新的替换旧的；多选模式切换勾选，
     已选报点标签加对勾/高亮；
   - 「完成」把结果写回表单对应字段并关闭弹窗；「取消」不改动。
3. chips 与弹窗两处状态实时同步；表单其他字段不受影响。

三、移动枚举扩展「W 一步」（不做自由文本——投法三字段必须受控，写错等于练错）
1. app.js 投法徽章 M 表加 "walk-step": "W一步"；编辑器「移动」下拉加选项「W 一步」，
   排在「W 前进」之后。
2. pb.py 的 move 枚举校验表同步加 walk-step（grep "shift-w" 定位）。
3. 徽章组合示例：walk-step + lmb + jump → 「W一步·左键跳投」。

四、编辑器 Esc 返回上一级
1. 全局 onKey 优先级最前加：state.editingId 存在时 Esc = 取消编辑返回
   （编辑前位置：列表或详情，走既有取消逻辑，不保存）；其后再走原有的
   entryView/钻取/清搜索分支。
2. 编辑器内若焦点在文本输入里，Esc 同样生效（输入框先失焦再返回，不弹确认）。

五、收尾
1. index.html 三处 ?v= 递增到 20（当前 19）。
2. pb lint / pb build / pb pack 跑一遍。

红线：投法三字段保持受控枚举，不开放自由文本；pb.py 解析/写回与旧条目双向兼容
（标量 target 的既有条目不许坏）；不动 lightbox 缩放（I12）与重置按钮（I11）。
验收清单（逐项自检，强刷 ?v=20 后）：
- [x] 编辑器起点是 chip + 地图选点（无长下拉）；目标/关联是 chips 多选；
      「在地图上选」弹窗三模式正确写入对应字段，弹窗内搜索框能实时过滤报点标签
- [x] 把「二箱后 L 位火」的目标用弹窗重选为 二箱 + 电梯位（多选），保存后
      target 落为数组，目标模式钻取两个点都能找到它
- [x] 移动选「W 一步」→ 徽章「W一步·左键·跳投」（与 AGENTS.md「Shift+W·双键·跳投」同形态）；
      pb lint 接受 walk-step
- [x] 旧标量 target 条目打开/保存正常，无回归（B 门火往返后 target 仍为标量 "B门"）
- [x] 编辑器内 Esc 返回上一级（详情页/列表页均正确回落）；列表页 Esc 仍清筛选；
      选点弹窗 Esc 只关弹窗不影响编辑
- [x] lint / build / pack 通过；控制台无报错（修复 EDITOR_KEY 后 unhandledrejection 清零）
```
