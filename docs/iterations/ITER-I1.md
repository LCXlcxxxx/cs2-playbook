## 粘贴提示词

```text
按 AGENTS.md 规范执行本次查看器迭代（迭代 I1）。先读 assets/js/app.js 熟悉现有结构：
state（含 drill/drillTarget/accOpen）、render() 分支（战术板地图 calloutMapCard / 二级钻取
drillCard / 道具折叠栏 accordionCard / 编辑器 entryEditor）、缩略图大图面板 thumbPopup、
匹配函数 spotNameMatch / originIs / targetIs / canonicalCallout。

一、lightbox（展开大图）支持左右切换
1. openLightbox 增加图片上下文：调用方传入该条目的图片数组与当前下标。两个入口：
   - 折叠栏大图面板的「展开大图」（pop-zone.mid）：从面板当前停留的那张开始；
   - 道具卡片的大图：从被点的那个槽位开始，图片数组为该条目全部已收录图片。
2. lightbox 界面：左右各一个点击区（‹ 上一张 / › 下一张，首尾循环），底部标题显示
   「条目名 · N/M」；键盘 ← / → 同样切换（在全局 onKey 里加 lightbox 分支，优先于其他快捷键）。
3. 样式与 #thumb-pop 一致（半透明底、悬停高亮），左右点击区各占 26% 宽。

二、战术板双向钻取（起点 ⇄ 目标）
1. 报点图卡片头部「⚙ 编辑报点」右侧加两个模式按钮（图标+文字）：「道具起点」（默认选中）
   与「道具目标」。state.drillMode = "origin" | "target"，写入 localStorage（key pb-drill-mode），
   下次打开保持上次模式。
2. 一级地图点击地名时按当前模式钻取：
   - 道具起点模式：originIs 严格匹配 → 二级图显示该起点可达的「目标」标签（含条目数）；
   - 道具目标模式：targetIs 严格匹配 → 二级图显示能「丢到这里的起点」标签（含条目数）。
   两级的标签点击都进入折叠栏（语义顺序随模式）。
3. 二级页与折叠栏的方向文案随模式：起点模式「白车 → 超市窗口」；目标模式「超市窗口 ← 白车」。
4. 一级地图上，当前模式下"有对应条目、可进入二级页"的点位右下角加小角标
   （起点模式=小投掷图标，目标模式=小圆点），无条目的点位不加，一眼可辨。
5. 匹配规则：全程严格同名（originIs / targetIs / canonicalCallout），禁止子串包含——
   「楼梯」不得误连「下水道楼梯/跳台楼梯」。

三、顺手修
- 浏览器缓存导致改版看不到：index.html 的 app.js / style.css 引用带 ?v= 版本号，每次改版递增。

红线：不改数据文件结构与 pb.py；条目 status 仍只能在 pb verify 里改。
验收清单（逐项自检）：
- [ ] lightbox 左右点击区与键盘 ←/→ 切换、循环、N/M 计数正确
- [ ] 折叠栏大图面板「展开大图」从当前张进入 lightbox
- [ ] 「道具起点」模式：点白车 → 二级图只有「超市窗口」→ 折叠栏 → 展开/编辑/取消全链路正常
- [ ] 「道具目标」模式：点超市 → 二级图显示「B 二楼」等起点 → 点起点进折叠栏
- [ ] 模式按钮刷新后保持；方向文案随模式（→ / ←）
- [ ] 起点模式行为与迭代前一致（白车 → 超市窗口）
- [ ] 一级地图角标只出现在可进入二级页的点位上
- [ ] 点「下水道楼梯」不误连警家闪（严格匹配仍生效）
```
