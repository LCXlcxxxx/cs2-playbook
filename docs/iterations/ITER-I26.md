# 迭代 I26 开发包 — 分拣台：行选中事件隔离（修点击穿透）+ 预览里直接加行

> 用法：在项目根目录 `D:\AI agent\ZCode data\CS2` 打开新的 ZCode 会话，把下面代码块整段粘贴执行。
> 背景：用户实测两问题——① 行内下拉/输入框的点击会穿透触发行选中/反选（点选项=行被反复选中，
> 无法正常操作）；② 大图预览分拣时发现"这张属于新道具"，必须关预览→回表格加行→重进，希望预览里直接加行。

## 粘贴提示词

```text
按 AGENTS.md 规范执行查看器修复迭代（迭代 I26）。只改 assets/js/app.js + style.css。
动手前先读分拣台的行选中实现（grep「分拣台」定位 render 与点击绑定）与大图预览底栏
（I24 的 1/2/4 分配条）。

一、修行选中点击穿透（用户主诉：点行内下拉选项 = 行被选择/反选）
1. 根因方向：行级 click 监听把行内控件的冒泡点击也当成了「选中/反选本行」。
2. 修复原则（二选一或并用，以实测手感为准）：
   a. 行选中只由**专用选中区**触发：行首加一个明显的选中圆圈/复选块，
      点它才切换选中；行内其余区域不触发行选中。
   b. 或保留点行选中，但事件处理里排除交互元素：
      ev.target.closest("select, option, input, button, label, .chip, a") 命中则忽略，
      并对这些容器统一 stopPropagation。
3. 回归确认：行内所有控件（阵营/类型/键位/移动/投掷/阶段/已实测/备注/图槽 ×/上传）
   单独操作时，行的选中状态必须纹丝不动；点行首选中区或空白区才切换。

二、大图预览底栏加「＋ 加行」
1. 预览底栏（1/2/4 分配条）末尾加「＋ 加行」按钮：新建一行（走既有加行逻辑，字段默认，
   id 自动生成）并**立即把目标行切换为这一新行**，预览保持打开——随后按 1/2/4 直接给新行入坑。
2. 底栏的「→ 行标识」显示同步更新为新行 id/标题。
3. 加行不受「全部导入」进行中状态影响； Esc 仍是关闭预览。

三、收尾
1. pb build（?v= 自动递增，以 grep 为准）+ pb lint + pb pack。

红线：不改分拣台的导入/写盘管线与 I24 已交付的预览交互语义；不碰数据文件。
验收清单（逐项自检，强刷后）：
- [ ] 操作行内任意下拉/输入框/按钮/图槽，行选中状态不发生变化
- [ ] 点行首选中区（或空白区）正常选中/反选，高亮清晰
- [ ] 预览底栏「＋ 加行」：新建行自动成为目标行，1/2/4 直接给新行入坑，底栏行标识同步
- [ ] 快速流全程（选中行 → 预览 1/2/4 → 加行 → 继续 1/2/4 → 全部导入）无一次误触反选
- [ ] lint / build / pack 通过；控制台无报错
```
