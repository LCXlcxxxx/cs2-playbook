# 迭代 I33 开发包 — 分拣台选点一次写回（修目标丢失）+ 槽位大图复看 + 预览里选起点/目标

> 用法：在项目根目录 `D:\AI agent\ZCode data\CS2` 打开新的 ZCode 会话，把下面代码块整段粘贴执行（单阶段）。
> 前置：按顺序执行 I30 → I31 → I32 后再跑本包（同改 app.js 分拣台/弹窗区域）。
> 背景（用户批量导入实战三痛点之二）：① 选起点弹窗里顺手把目标/关联也选了，确定后目标丢失要重选一遍；
> ② 图入坑后无法复看大图（点槽=弹文件选择）；希望大图预览里直接选起点/目标，关联自动不用人选。

## 根因速览（已核实）

- **目标丢失**：`openSpotPicker`（app.js ~1311-1320）是编辑器三页签弹窗 `openCalloutPicker`（~1219）的薄包装，
  弹窗本身有三个页签（起点/目标/关联，I13 形态），但写回回调只取 startTab 对应的一个字段——
  `onDone: res => onDone?.(mode === "origin" ? res.origin : res.target)`，用户在弹窗里切页签选的目标/关联全被丢弃。
- **关联本就自动**：分拣台导入时 `spots = 起点+目标去重`（~2948），弹窗里的「关联」页签在分拣台选了也不生效——纯误导，应隐藏。
- **槽位无复看**：已填充槽点击=打开上传文件选择（~3148 slotBox 分支），无查看大图入口。
