# 迭代 I22 开发包 — 录入分拣台（Excel 式批量导入工作台）

> 用法：在项目根目录 `D:\AI agent\ZCode data\CS2` 打开新的 ZCode 会话，把下面代码块整段粘贴执行。
> 背景：用户自助批量录入——Excel 式表格：一行一条道具，列 = 名称/起点/目标/投法/备注 + 三个图片坑，
> 图片从「素材池」拖坑或直接上传，填完一键批量入库。复用现有写入管线，不碰数据文件格式。

---

## 粘贴提示词

```text
按 AGENTS.md 规范执行查看器迭代（迭代 I22：录入分拣台）。改 assets/js/app.js + style.css。
动手前先读可复用件：uploadSlotImage / compressToSlot / writeEntryImage / dumpEntryMd /
writeEntryFile / idb 待写图管线 / I13 报点选点弹窗 / refreshSyncBadge。
不碰 pb.py 与数据文件格式。

一、入口与布局
1. 道具 Tab 工具栏加「📥 分拣台」按钮 → 全屏 overlay 页（顶部「← 返回」），不影响既有 Tab。
2. 分拣台三区：
   - 顶部素材池：扫描已关联项目文件夹下「文件夹批量录入/」的全部图片（递归，按子文件夹
     分组、组内按文件名/修改时间排序），缩略图网格展示；缩略图上标注来源子文件夹名；
     点缩略图 = 选中（拿起），再点目标槽 = 放下；也支持从资源管理器直接拖文件进槽。
   - 中部表格：一行一条道具，列 = 英文代号 | 标题 | 起点 | 目标(多选) | 类型 | 键位/移动/
     投掷 | 阶段 | 已实测✓(默认勾选) | 备注 | 站位槽 | 瞄点槽 | 落点&效果槽。
     「＋ 加行」新增空行；行可删除。类型/键位/投掷用与条目编辑器相同的受控枚举下拉；
     起点/目标复用 I13 选点弹窗（起点单选、目标多选）。
   - 底部：「全部导入」主按钮 + 问题行提示区（缺 id/缺起点/缺图的行列出，可跳过该行只导完整行）。
3. 行的地图 = 行对应素材子文件夹名匹配 data/maps.json 的 cn 名；匹配不到用顶部全局地图选择。
   id 自动预填：<map去前缀>-t-<type>-<英文代号>，可改，保存时校验唯一与格式（沿用 pb 规则）。

二、图片坑交互
1. 三种入坑方式：素材池点选放下 / 资源管理器拖文件进槽 / 点槽上传（文件选择器）。
2. 入坑即走 compressToSlot（宽 >1920 压缩）预览；来源标记「素材池」的图导入时用
   writeEntryImage 直接写盘（已关联文件夹），未关联时进 IndexedDB 待写图管线（复用现有）。
3. 一个素材图被放进某槽后，从素材池移除（防一图多用）；行删除时归还素材池。

三、批量导入
1. 「全部导入」逐行生成条目：dumpEntryMd 组装（status 按行勾选 = verified+checked 今天，
   未勾 = draft；source.kind=self creator=自己；spots 由起点/目标选择器结果带入），走既有
   writeEntryFile 写 data/entries/*.md；图片 writeEntryImage 写 media/<map>/<id>/。
2. id 冲突行：跳过并列出；部分成功部分跳过时 toast 汇总「成功 N 条，跳过 M 条（原因）」。
3. 导入成功的行：素材源子文件夹（若已空）移入「文件夹批量录入/已录入/」（用文件夹句柄移动）。
4. 完成后 refreshSyncBadge + 提示「双击 同步并打包.bat 固化」。

四、收尾
1. index.html 三处 ?v= 以 grep 实际值递增（当前 50 → 51）。
2. pb lint / pb build / pb pack 跑一遍。
3. docs/RECORD.md 的「批量通道」节补一段：自助通道=分拣台；agent 通道=文件夹+一句话（两者并存）。

红线：不改 pb.py 与数据格式；不碰 lightbox 缩放/编辑器选点/重置按钮既有行为；
分拣台导入的条目走既有覆盖层与写盘管线，不另起炉灶。
验收清单（逐项自检，强刷 ?v=51 后）：
- [ ] 素材池正确列出 文件夹批量录入 下全部图片并按子文件夹分组
- [ ] 三种入坑方式都可用；一个图只进一个坑；行删除归还素材池
- [ ] 加 2 行完整数据 → 全部导入 → 条目与图片落盘正确（id/署名/状态/槽位），
      空子文件夹移入 已录入/
- [ ] 缺 id/起点的行被拦截并列出，完整行不受影响
- [ ] 已实测勾选行 status=verified+checked 今天；未勾为 draft
- [ ] lint / build / pack 通过；控制台无报错
```
