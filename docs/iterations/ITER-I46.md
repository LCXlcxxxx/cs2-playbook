# 迭代 I46 开发包 — 导入弹层「被拦下」计数误报：归档提示 ≠ 拦截（分类拆分）

> 用法：在项目根目录 `D:\AI agent\ZCode data\CS2` 打开新的 ZCode 会话，把下面代码块整段粘贴执行（单阶段）。
> 背景：用户新图首录成功（图片已显示）后，弹层仍显示「1 条被拦下」——内容却是
> 「『炼狱小镇』还有 60 张未入坑，文件夹保留在素材池」。这是 `sortMaybeMoveGroup` 的**归档状态说明**
> （文件夹里还有剩图所以不移入「已录入」，属正常状态），被 sortImportAll 原样 push 进 problems，
> 弹层用 `problems.length` 当「被拦下」数（~4491）→ 正常状态被报成拦截，误导。

## 现状速览（已核实）

- `sortMaybeMoveGroup` 返回三种字符串（~4276-4300）：「还有行未导入，暂不移入已录入」「还有 N 张未入坑，
  文件夹保留在素材池」（均为 info）、「移入已录入失败（文件可能被占用）」（真 warn）；另有 moved/null。
- sortImportAll 组收尾循环（~4405-4410）把这些返回值全部 `problems.push(r)`；弹层头部
  （~4491）`${problems.length} 条被拦下`。
