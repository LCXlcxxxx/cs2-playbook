# 迭代 I24 开发包 — 分拣台可用性修复：大图预览快速入坑 + id 自动生成 + 修选点弹窗

> 用法：在项目根目录 `D:\AI agent\ZCode data\CS2` 打开新的 ZCode 会话，把下面代码块整段粘贴执行。
> 背景：用户实测分拣台三个问题——素材缩略图太小没法分拣；「英文代号/id」不知所谓；
> 「+ 选起点」「+ 选目标」点击无反应。不碰数据文件格式。

---

## 粘贴提示词

```text
按 AGENTS.md 规范执行查看器迭代（迭代 I24）。只改 assets/js/app.js 与 style.css。
动手前先读分拣台现有实现（grep「分拣台」定位）与条目编辑器的 I13 选点弹窗
（#ef-origin-chips 一带），修第三项前先开控制台看点击「+ 选起点」有无报错。

一、素材池：点图放大预览 + 键盘快速入坑（修问题 1）
1. 点素材缩略图 → 打开大图预览层（复用 lightbox 的暗底/尺寸风格）：大图 +
   底部分配按钮「1 站位 / 2 瞄点 / 4 落点&效果 / 跳过 →」+ 关闭。
2. 快速分拣流：先在表格点一行选中为目标行（行高亮常显，再点同行取消）；
   预览里按键盘 1/2/4（或点按钮）把当前图放入目标行对应槽位，随后自动跳到
   素材池下一张未分配的图——三连按完成一条道具。
3. 无选中行时按 1/2/4：toast 提示「先在表格点选目标行」，不丢图。
4. 「跳过 →」仅前进；预览内 ←/→ 手动前后翻；Esc 关闭预览。

二、英文代号/id 列重构（修问题 2）
1. 表格默认**隐藏**「英文代号」「id」两列。
2. id 全自动生成：<map去前缀>-t-<type>-<两位序号>（如 dust2-t-smoke-04），
   全局唯一性校验，冲突自动跳号；以灰色小字显示在「标题」单元格下方（只读标识）。
3. 表格上方加一行说明小字：「id 是道具的文件名，不参与搜索/地图选点/钻取，无需填写；
   起点和目标才是在地图上点选的」。
4. 标题单元格加「高级」小链接：点开展示 id 输入框供进阶修改（可选实现，不影响验收）。

三、修「+ 选起点 / + 选目标」点击无反应（修问题 3）
1. 先诊断：控制台看点击是否抛错；常见根因是分拣台按钮未实例化 I13 选点弹窗，
   或弹窗写回目标写到了条目编辑器表单而非分拣台行状态。
2. 修复：把选点弹窗抽成共用组件 openSpotPicker(mapKey, {mode, initial, onDone})
   （mode = origin 单选 / target 多选），条目编辑器与分拣台都调它；
   分拣台的 onDone 写回当前行的起点/目标并刷新该行 chips。
3. 弹窗内地图 = 当前行地图；行地图匹配不上时用分拣台顶部的全局地图下拉（现状保留）。
4. 修完自测：选起点 → 弹窗 → 点「厕所」→ 行 chips 显示「厕所」；
   选目标 → 多选「二箱」「电梯位」→ chips 两枚。

四、顺手
1. 分拣台顶部加一行三步流程提示：「① 表格点行选中 → ② 点素材图放大，按 1/2/4 入坑 →
   ③ 全部导入」。
2. pb build（?v= 自动递增）+ pb lint + pb pack。

红线：不碰数据文件格式与已导入管线；不碰 I13 条目编辑器的既有行为（重构为共用组件后
条目编辑器行为必须不变）；lightbox 缩放（I12）不受影响。
验收清单（逐项自检，强刷后）：
- [ ] 点缩略图出大图预览；选中行后 1/2/4 入坑并自动跳下一张；三连按完成一条
- [ ] 无选中行按键有 toast 提示
- [ ] 表格无 英文代号/id 列；自动 id 唯一；标题下灰色小字可读
- [ ] 「+ 选起点」「+ 选目标」弹窗正常打开、选择后行 chips 更新，导入的条目
      origin/target 落库正确
- [ ] 条目编辑器的选点弹窗回归正常（共用组件无回归）
- [ ] lint / build / pack 通过；控制台无报错
```
