   ① 这个册子怎么用？
      双击 index.html 打开；顶部搜索框输文字找道具，四个图标按烟雾/闪光/燃烧/高爆筛选；

   ② 我在网页里做的修改存在哪？
      先存进「浏览器的小抽屉」——每个浏览器各有各的抽屉，换浏览器/清缓存就看不到。
      点过「关联项目文件夹 + 开启自动保存」之后，修改会在 1 秒内自动写进项目文件夹的文件里
      （那才是真身，以后换浏览器打开都一样）。
      队长版和朋友版的区别：发朋友的压缩包里没有源文件，朋友的修改永远只在他的小抽屉里——

   ③ 顶部出现「● N 条修改待写入文件」怎么办？
      浏览器重启后授权会自动过期，这是正常安全行为。点工具栏 🔑 重新授权一下，
      修改会自动写进文件，提示随即消失。不处理也不丢——它一直替你留着。
   ④ 为什么改完要双击「同步并打包.bat」？
      它做两件事：把文件里的数据"编译"进网页用的数据文件（不点它，别的电脑上就还是旧内容）；
      以及打好发给朋友的压缩包。它只在队长的电脑上用（背后用到 Python，队长电脑已装好）；
      朋友什么都不用装。
   ⑤ 朋友怎么把自己喜欢的道具加进大家的册子？
      在网页里新增道具、传好截图 → ⚙ 设置 → 📤 把我的修改分享给队长 → 把下载的文件微信发队长 →
      队长 ⚙ → 📥 导入。导入的都算「待验证」，队长亲自进游戏试过才转成绿色的「已实测」，
      下次发的包大家都有。

      和「开启自动保存」；担心修改丢失 → 任何被"作废"的修改都进了搁置区留底，
      ⚙ 设置里能看到并导出，绝不会无声消失。
