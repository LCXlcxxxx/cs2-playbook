- 归还链路（× 取下 ~3081 / 换图 ~2856 / 删行）：按 poolKey `pool.set(key, poolItem)` 原样还原——**克隆份只要 poolKey 唯一即可无损往返**，无需动归还逻辑。
- 槽位 UI（~3335）：已填充槽有 ×（data-clrslot）。
