# 迭代 I15 开发包 — 报点编辑器去开发化：移除导出/自动覆盖按钮，自动保存常态化

> 用法：在项目根目录 `D:\AI agent\ZCode data\CS2` 打开新的 ZCode 会话，把下面代码块整段粘贴执行。
> 背景：用户要求网页上不出现开发相关控件——「自动覆盖已开启」「导出 callouts.json」按钮移除；
> 编辑改动应实时自动写回数据文件（技术上保留一次性的「开启自动保存」授权，这是浏览器
> 安全模型的要求，无法省略，但以正常功能的形态出现）。
