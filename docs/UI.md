# CS2 Playbook — 查看器行为规格（UI.md）

> 只写「当前行为」，不写迭代史（历史见 docs/PROGRESS.md 台账）。改行为先改这里再改代码（迭代五步①）。
> 硬底线（AGENTS 一）：单栏禁双栏、file:// 直开、正文 ≥18px / 角标 ≥15px、数据只经 `build/data.js` 以 `<script>` 引入（禁止 fetch JSON）。

## 1. 顶栏（sticky）

- 控件从左到右：品牌 → 大 Tab「战术板 | 道具」（默认战术板）→ 地图下拉（记忆上次选择；顺序 ⚙ 自定义，第一位=默认图；无「全部地图」聚合项）→ 烟/闪/火/雷类型图标（可多选，同时作用于道具列表与战术板地图）→「📦」只看战术包开关 → 阵营 全部/T/CT（side=both 两侧都显示）→ 搜索框（`/` 聚焦）→ ⚙ 设置 → 🔑 项目文件夹 / 🔗 自动保存 重连按钮（仅授权过期态出现）→ 同步徽标（待写/搁置计数）。
- 搜索框下整行**快捷筛选 chips**（仅道具 Tab 显示）：单向烟 / 瞬爆闪 / 自助闪 / 灭火 / 跳投 / 跑投 / 已实测 / 简单 / 中等 / 困难。chip→谓词集中在 FILTER_CHIPS 配置；`dim`=互斥维度（跳投/跑投同属投法维、简单/中等/困难同属难度维——同维单选防恒空集），跨维 AND；选中实底高亮、末尾「✕ 清除」、会话内不持久化、Esc 与搜索同环清空。

## 2. 过滤组合语义（全 AND）

类型 ∧ 阵营 ∧ 地图 ∧ chips ∧ 搜索词 ∧ 报点筛选/钻取 ∧ 失效开关（broken/retired 默认隐藏，⚙ 可显示）。搜索分词 `/[\s,，、]+/`（含全角空格）逐词 AND，拼音逐词保留（全拼子串 + 首字母子序列 ≥2 字母）；难度快捷语法 `难度:简单` / `难度:困难` / `diff:easy`（值兼容中文与枚举、冒号全半角皆可；坏值恒假不当自由词）。chips 只作用道具 Tab——战术板图层与报点相关性链路不受影响。

## 3. 道具列表页

- 分组自上而下：⭐ 收藏置顶 →「📦 战术包」折叠区（每套装一行「📦 名称 (N 个道具)」，点击展开成员行复用列表行组件；成员仍保留在原 phase 分组=叠加视图；无套装条目时此区不出现；套装名 zh 序排序、展开状态会话内保持）→ phase 分组（默认/爆点/防守/回防/科研，按主 phase，一条只出现一次）→ 其他。
- 📦 开关开启=只看视图：仅显示套装折叠区 +「未分组」行（收藏/phase 分组整体隐藏），再点还原。
- 列表行组件：类型图标 → 标题（拉丁前缀弱化小字）+ tags 徽章（放不下整体裁切省略）→ 投法徽章（click×move×action 三字段自动组合中文，按 action/move 着色：跳投=蓝 / 走位投=绿 / 原地直投=灰，文案保留）→ 难度徽章（色点+简单/中等/困难；**点击=按该档过滤**，复用 chips 管线）→ 起点 → 目标 → 状态徽章（贴行最右）→ ⭐ 收藏。
- 键盘：J/K 或 ↑/↓ 高亮步进（按数据序）、Enter 进详情。

## 4. 详情页

- 结构：导航条（← 返回 / ‹ 上一条 / 下一条 › / 收藏）→ 状态色条+类型图标+标题+状态徽章（两段确认切「已实测」记今天日期，可退回待验证）→ oneline 大字 → meta（投法徽章 / 起点→目标 / 阶段 / 难度大徽章）→ 翻图面板 → 注意事项折叠 → 来源行（UP 主+URL+实测日期）→「所属战术包」chips（点击=打开 📦 只看视图并展开/定位该套装；无套装不显示）。
- 翻图面板：大图常驻 + 槽位 chips（基础槽 1-stand 站位 / 2-aim 瞄点 / 4-result 落点&效果 固定序，扩展槽按序追加；缺图「·缺图」虚线可选中）+ 左右半区在**有图的槽位**间循环 + 点大图进 lightbox + `[` `]` 翻槽 + 上传/替换（宽 >1920 自动压缩）+ 扩展槽删除（两段确认）+ 未同步角标。
- lightbox：左右 26% 点击区或 ←/→ 切图、滚轮以光标为锚缩放 1–8x、拖拽平移带边界、双击/+/−/0 复位、Esc 关闭。

## 5. 条目编辑器（卡片「编辑」/ 工具栏「＋ 新增道具」）

- 全字段网页内可改（**含 status**——「已实测」二次确认防误标；新增一律 draft）；起点（单选）/ 目标（多选）/ 报点关联（多选）chips + 地图选点弹窗（三页签 + 搜索过滤）+ 手动输入兜底；标签 chips（常用词表 + 全库已有标签按频次建议，回车/逗号/失焦/点建议添加）；战术包 chips（自由命名，全库已有套装名 datalist 自动补全）；难度三按钮 Radio + 快捷键 1/2/3（焦点在文本输入框时不劫持打字）。
- **智能默认（仅新建且未手动选过难度）**：跳投系（jump/crouch-jump）或原地/蹲下直投=简单；移动投（w/walk-step/shift/shift-w/run）=中等；tags 勾「低容错」→困难。手动点选即锁定本次编辑（再改投法/tags 不覆盖），重开编辑器恢复推荐；编辑已有条目绝不自动改。
- 图片槽位网页上传/替换；Ctrl+V 贴图直达最后聚焦的槽（文字粘贴零影响）。
- **打开即读盘**（已关联且非新增）：表单初值与保存基线以磁盘 .md 为准，有差异 toast 提示。
- 保存链路的用户可见表现见 §9；「标记已实测」两段确认后自动填 checked=今天。

## 6. 战术板（Tab 默认页）

- 互动地图：雷达底图 + 中文报点标注（data/callouts.json，u/v 0~1）；点击报点=按条目 `spots` 字段**精确过滤**进道具列表（保留顶栏已选类型/阵营，只叠加报点筛选；关联写 spots 不做正文模糊匹配）。
- 钻取：「🚀 道具起点」/「🎯 道具目标」模式——起点模式点地名显示可达目标二级图，目标模式反向；严格同名/别名匹配；「◎ 全部」=普通视图（报点筛选不进钻取）。
- 三图层切换（📍报点 / 💥道具 / 🕒时间轴，记忆选择）：
  - 💥 道具：可见条目按 target 报点坐标铺类型图标（同落点聚合 ×N、阵营描边）；点图标=起点→落点虚线 + 底部清单（点条目直达详情）；类型/阵营/搜索全管线联动。
  - ✏️ 调点（道具图层内开关）：同位重叠的道具自动环形散开（仅显示不存点），拖到真实落点才存 `pin_origin`/`pin_targets`；↺ 还原报点坐标。定位语义=**报点管区域、道具点管精准位置**。
  - 🕒 时间轴：角色标（①..⑤，钉在该角色第一个含 use 步骤的道具起点）+ 角色旁倒计时 chip 堆 + 每个指派步骤的真实投掷动线；步骤按倒计时排序（1:55=开局 0:00=结束）；text 留空显示自动生成「{起点}→{目标}，{投法}」。
- 战术板卡片：`##` 分节要点正文 + uses 道具缩略条（点击直达详情）+ 网页内创建/编辑（地图卡「＋ 新增战术板」/ 板卡「⚙ 编辑」，自动 id `<short>-plan-NN`，与道具同一套暂存-写盘-退役语义）。朋友分享/导入**不含战术板**。

## 7. 报点编辑器（地图卡「⚙ 编辑报点」）

拖拽/增删/改名即时生效并联动首页与选点弹窗；「开启自动保存」一次性授权 `data/callouts.json` 后改动**实时自动写回**（防抖 0.8s），授权后只显示被动状态小字——正常使用不出现导出/覆盖等开发控件（仅不支持该 API 的浏览器回退显示「导出」）；「还原默认」两段确认（防清空自加点）。报点读-改-写按名并集（同名以编辑器为准，删除/改名记 removed 名单防踩踏）。

## 8. Esc 语义链与键盘动线

- Esc：关 lightbox/弹层 → 清搜索/筛选/chips/报点 → 编辑器取消（不保存）→ 详情页回列表（战术板系来源回战术板）→ 道具列表切回战术板。
- 键盘汇总：`/` 聚焦搜索；列表 J/K 或 ↑/↓ + Enter 进详情；详情 ←/→ 上一条/下一条、Backspace 回列表、`[` `]` 翻图槽；编辑器 1/2/3 选难度；Esc 通链如上。

## 9. 数据链路用户可见表现（I19 语义：文件是唯一权威）

- 编辑先存浏览器覆盖层（暂存）并即时生效；已关联项目文件夹 = 同时直接写回 `data/entries/*.md`、`media/`、`tactics/*.md`、`data/callouts.json`。
- 顶栏徽标：「● N 条修改待写入文件」= 有待写暂存（点击=一键补写盘）；「● N 条修改已搁置（文件曾更新）」= 构建对账后退役的暂存（点击开 ⚙ 查看/导出搁置区留底）。
- 构建对账：data.js 的 `builtAt` ≥ 暂存 `savedAt` → 暂存自动退役进搁置区（可导出留底，绝不静默丢弃）；开机自动补写上次未写完的修改。
- ⚙ 设置：📖 册子待办（缺基础图/待验证/已失效/已实测四组计数+点击直达补图）、地图排序、自定义移动方式、搁置区（计数/导出/两段清空）、📤 分享我的修改 / 📥 导入朋友的修改（导入一律 draft、不覆盖队长侧实测状态与同名报点）、失效也显示开关、📖 使用说明（help.html）。

## 10. 布局与自适应

- 单栏长滚动：竖屏 1440×2560 基准（栏宽 1200px 居中）；>1440 视口主栏渐进加宽至 1560px 上限；宽区文本块 900px 行宽上限（图宽文窄，图片不受限）。横屏打开自动两侧留白，不搞断点双栏。
- **留白区锚点导航**（道具列表页专用）：视口 >1200 且右留白 ≥260 且屏上 ≥2 个组头才懒创建（竖屏元素不存在、零开销）；目录=真实渲染的组头自动收录，scrollspy 高亮 + 点击平滑滚动；**红线：浮动目录不承载内容本体、不渲染详情/正文/图片，主内容流永远单栏（非双栏）**。
- 空态：过滤无结果提示「Esc 清空筛选」；地图无道具给「＋ 新增道具」引导占位。
